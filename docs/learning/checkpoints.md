# Learning Checkpoints

At the end of each phase, answer these without looking at notes.

## Java
- Why use records?
- When should Optional be used?
- Difference between List/Set/Map?
- What is a stream?
- Why BigDecimal for money?
- What happens when two threads modify the same object?

## Spring
- What is dependency injection?
- What is a Spring bean?
- Why separate controller/service/repository?
- What does @Transactional mean?

## JPA
- What is the persistence context?
- Lazy vs eager?
- What causes N+1?
- Why use migrations?

## Security
- Authentication vs authorization?
- Access token vs refresh token?
- Why hash passwords?

## Banking
- What makes a transfer atomic?
- What is double-entry accounting?
- What is idempotency?
- Why is concurrency dangerous for balances?

## Distributed systems
- Why Kafka?
- What is eventual consistency?
- Why can a consumer receive the same message twice?
- Why does Redis not replace PostgreSQL as the financial source of truth?
