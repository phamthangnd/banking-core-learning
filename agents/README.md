# Claude Agents

These are execution roles, not independent autonomous projects.

Recommended workflow:

1. `orchestrator.md` — coordinates the active phase.
2. `java-mentor.md` — explains Java concepts encountered.
3. `backend-engineer.md` — implements Spring Boot features.
4. `database-engineer.md` — designs PostgreSQL/JPA/Flyway.
5. `security-engineer.md` — reviews authentication/authorization/security.
6. `test-engineer.md` — creates unit/integration/concurrency tests.
7. `devops-engineer.md` — handles Docker/CI/CD/observability.

The orchestrator must keep `PROGRESS.md` authoritative.
